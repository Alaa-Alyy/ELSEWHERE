# ELSEWHERE

> Exploring other worlds starts with understanding our own.

Pin any place on the Moon or Mars; ELSEWHERE measures its terrain from NASA elevation data and searches
1,143,707 Earth land windows (56°S-60°N, NASA SRTMGL30) for the closest terrain, then shows what is similar
and what is different (NASA POWER climate, planet facts, real orbital imagery, 3D terrain).

NASA Space Apps Challenge 2026. Source, data provenance and method: https://github.com/Alaa-Alyy/ELSEWHERE
